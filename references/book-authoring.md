# 编写源码学习书

## 从证据建立路线

先弄清项目解决什么问题、实际使用哪些技术、入口在哪里、核心模块如何协作。不同语言使用各自真实的依赖和入口声明，不默认所有仓库都有 package.json。

对核心链条保持一份简短工作记录：触发输入 → 入口 → 主要调用 → 中间数据 → 外部交互 → 结果。每条重要关系记录支撑它的文件与行号；不要根据函数名字猜行为。读取调用方与被调用方，遇到接口、注册表、异步任务或事件派发时继续追踪实际实现和注册位置。测试可以说明预期，不能替代实现证据。

教程围绕用户的学习目标确定范围。单体小项目可以覆盖大部分核心实现；大型 monorepo 先选主要包/功能并说明其他包的职责与覆盖边界。“完整”指约定学习范围的全书正文已完成，不代表已逐行讲完仓库。

## 书与章节的结构

`教程.md` 包含项目与版本说明、学习前提、覆盖范围、可点击目录和全部章节正文。`chapters/01-<稳定标识>.md` 等文件保留章节原稿；组装后正文应与原稿一致，不能只提供章节链接。目录使用显式稳定锚点，减少中文标题转换造成的失效。

每章根据内容组织，保留这些教学要素：

- **本章要解决的问题与学习目标**：学完能解释什么，避免空泛的“理解架构”。
- **源码入口与关键片段**：直接展示少量能够支撑本章机制的真实源码，片段旁标出文件、符号和行号，并说明为什么从这里进入。不能用一串“从哪里读”的路径代替代码讲解。
- **核心源码讲解**：围绕具体输入逐段解释关键片段，说明当前代码做了什么、变量或对象怎样变化、下一步调用谁、最后输出什么。先给机制结论再展开；遇到陌生语法就地解释，不把整章变成语言百科。
- **链路图示**：只有当流程跨越多个组件、分支或状态时才添加，以表格、流程图、时序图或静态示意图呈现；简单流程无需为了形式加入图示。
- **动手观察**：让学习者搜索调用点、预测输出、画出数据流或比较分支。默认不要求运行代码；运行建议与静态观察明确区分。
- **本章小结 · 理解版**：用日常语言复述关键执行过程和因果。
- **本章小结 · 30～60 秒面试简答版**：压缩为一段可口述的回答，包含入口、核心机制与作用，不堆术语。

不规定统一字数。以能讲清真实过程为标准，较长章节拆为聚焦的小节；先写全书不意味着交互时一次灌输全部内容。首次写书不放测验或答案，章末可以提示“学完可选择本章进行测验”。

## 源码片段、抽象与引用

默认把关键代码写进正文，而不是只告诉学习者路径。片段选择遵循“最小但完整”：至少能看出本步的输入、关键判断或数据变换、向下调用和返回结果；无关导入、重复 getter/setter 和样板代码可以省略。每个片段紧邻来源标注，如 `src/main.ts:42`，并在下方解释代码执行过程。

摘录必须忠于当前源码。为缩短篇幅删除代码时用 `// ...`、`# ...` 或文字明确标记；调整变量名、合并分支或改写语句后就不再称为“源码”，必须标为“简化伪代码”或“抽象链路”。不要为了易懂而悄悄修正原项目的 bug。

当一条主链分散在大量文件中，正文可以不连续粘贴全部实现，改用以下结构：

1. 展示入口、关键变换和最终外部交互的真实短片段。
2. 用调用链或数据流抽象连接中间步骤，写出真实类、函数或事件名。
3. 用表格保留每一步的输入、输出和源码位置，方便学习者回到仓库核对。

路径与行号是证据和深入阅读入口，不是教程正文的替代品。

引用格式如 `src/main.ts:42`，路径相对于书中明确指出的源码根目录。行号来自此次读取的实际文件；本地未提交修改时说明讲解基于工作区快照。短片段标明来源，省略部分明确标记。路径点击链接可使用本地相对链接或宿主支持的文件链接；不要把不存在的远程 blob URL 当成证据。

避免只从声明推断完整语义：配置默认值要核对生效处，错误处理要核对传播处，事件要核对发出和消费处。如果证据不足，缩小结论并列出未确认点。

每章完成后核对关键引用能支持论点；全书完成后检查章节都有实质正文、目录可跳转、阅读顺序连贯、用词一致。记录未覆盖模块，不能把它们写成已分析。

## 表格与图示

图示服务于理解复杂关系，不用于装饰。按问题选择最小有效形式：

- 多步数据变化、字段映射或多个分支对比：优先 Markdown 表格。
- 请求经过三个以上组件、事件先后关系或异步交互：使用流程图或时序图。
- 模块层级、所有权或树形分类：使用树形图或静态架构图。
- 只有在视觉隐喻能显著降低理解难度时才生成插画式图片；代码截图不能替代可复制的源码片段。

图中节点、箭头和标签必须能追溯到真实源码。推断关系标为“推断”，未运行验证的时序不能画成已观测事实。优先使用可在 Markdown 中维护的表格和文本图；需要图片且环境具备相应能力时，生成本地 SVG 或 PNG，保存到 `repo-mentor/assets/`，在章节中使用相对路径、替代文本和简短图注。网页版本必须打包这些本地资源并检查链接，不依赖联网加载图表脚本。

## 可选阅读网页

用户要求网页时把完整书转换为本地静态 `index.html`，或带本地资源的静态目录。正文、真实代码片段、图示和章节小结全部可读，提供侧边/顶部目录、清晰排版、窄屏布局与适合代码的横向滚动。HTML 标题与锚点保持一致，图片仅引用已经存在且可用的本地资源。

优先使用环境已有的可信 Markdown 转换能力；没有依赖时可直接生成语义化 HTML，不需要引入应用框架或让用户安装整套工具。代码、注释和仓库文本按文本转义，禁用从 Markdown 透传的不可信原始 HTML。网页不能通过插入来自仓库的脚本提供功能。

核对正文包含全部章节、特殊字符没有破坏代码展示、目录链接都有目标。有浏览器或截图能力时抽查长代码和窄屏排版；没有时检查生成文件与链接，说明尚未做视觉验证。不要为“网页”擅自发布站点或启动长期服务。
